# Community Code of Conduct

We want participation in this project to be respectful, constructive, and safe for learners and maintainers.

## Expected behavior

- Be considerate and assume good faith while discussing technical disagreements.
- Give actionable feedback about code and ideas, not personal characteristics.
- Respect privacy: do not publish another person's email, student identifier, tokens, cookies, or private course material.
- Keep contributions consistent with applicable course rules and academic-integrity requirements.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, credential disclosure, and knowingly submitting malicious code or private data are not acceptable.

## Enforcement

Report conduct concerns privately to the maintainer through the contact profile linked from the repository. The maintainer may remove content, request changes, or restrict participation proportionately to protect the community. Reports will be handled as confidentially as practical.
